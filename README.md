# Python & Data Science Fundamentals

**Author:** Keerthana R
**Program:** B.Tech Artificial Intelligence and Data Science, Chennai Institute of Technology

A beginner-friendly Jupyter/Colab notebook covering the fundamentals of Python for Data Science.

## Objectives covered

1. Installing Python and setting up Google Colab / Jupyter Notebook
2. Python basics for Data Science
3. Practice with variables, loops, functions, lists, dictionaries and file handling
4. Data Science concepts and real-world applications

## What's inside

| Section | Topics |
|---|---|
| 1. Environment setup | Colab and local Jupyter setup, environment check |
| 2. Python basics | Variables and data types, conditionals and loops, functions, lists, dictionaries, file handling (text and CSV) |
| 3. Practice exercises | FizzBuzz, palindrome check, student report |
| 4. Data Science concepts | Workflow, a mini Pandas analysis with cleaning, summary statistics and charts, real-world applications |

## How to run

**Google Colab (easiest)**
1. Open [colab.research.google.com](https://colab.research.google.com)
2. File → Upload notebook → choose `Python_DataScience_Fundamentals.ipynb`
3. Runtime → Run all

**Local Jupyter**
```bash
pip install notebook pandas matplotlib
jupyter notebook Python_DataScience_Fundamentals.ipynb
```
